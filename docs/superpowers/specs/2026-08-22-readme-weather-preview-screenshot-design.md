# README 天气预览效果图设计

## 目标

在 `README.md` 中展示当前天气看板的完整网页预览效果，让读者无需启动本地服务器即可了解屏幕布局。

## 展示方案

- 使用仓库现有 `weather-preview/` 页面生成截图，不修改天气页面布局。
- 截取完整网页预览框架，包括页面背景、墨水屏外框和屏幕内容，不只裁切 768x552 画布。
- 使用桌面视口生成清晰 PNG，并确保整块预览框架完整可见、无滚动条遮挡、无内容重叠。
- 图片保存为 `docs/images/weather-dashboard-preview.png` 并纳入 Git。
- 在 README 的“深圳天气页”功能说明后插入效果图。
- 图片使用简短替代文本；说明文字单独放在图片下方，说明这是与设备共享 768x552 坐标的网页预览，实时接口不可用时可能显示示例数据。

## 验证

- 在浏览器中确认截图内容完整且天气布局可读。
- 检查 PNG 文件可识别、尺寸合理且不是空白图片。
- 检查 README 图片路径有效、Markdown 格式正确。
- 运行现有天气预览测试以及 `git diff --check`。

## 范围

本次只新增效果图、更新 README，并记录本设计；不修改固件、网页预览实现或现有未提交文件。
